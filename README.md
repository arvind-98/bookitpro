# BookitPro — Accounting software for Canadian businesses

A modern, responsive marketing website for BookitPro, a web-based accounting and tax management platform.

## Run locally

Built with Next.js, React and TypeScript.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this repository into Vercel and deploy using the default Next.js settings. No backend or environment variables are required for the marketing site.

## Product scope

The site presents capabilities in the related accounting application: bookkeeping and general ledger, customer invoicing and estimates, expense and bill tracking, banking/transactions, tax workflows including GST/HST, payroll/time tracking, and financial reporting. Dashboard figures shown are illustrative UI examples and not live customer or financial data.

## Production configuration

The contact/interest form is currently front-end-only, and sign-in/demo links are page anchors. Connect these to the production API, authentication destination, and contact/demo workflow before public launch.
